Commands

detectPrint the expected handoff file path for the current repo, exiting 2 if it does not exist yet.
refreshCreate or repair the .ctx/ directory layout and add gitignore rules for state files.
handoffRecord session metadata (build status, test status, notes) and append a log entry to the handoff file.
handonPrint the open and blocked items from the handoff file, grouped by priority, ready for triage.
handoverRender a concise markdown brief from the current handoff state and write it to .ctx/HANDOVER.md.
handupWalk the directory tree, collect handoff state from each repo found, and emit a machine-readable JSON summary.

Detect and refresh

hj detect resolves the canonical handoff file path for the current repo and exits 2 when the file does not exist yet — useful for scripting and conditional bootstrap. hj refresh creates the .ctx/ directory structure and writes gitignore rules so state files are never accidentally committed.

Generate the handover brief

hj handover renders the handoff YAML into a compact markdown document written to .ctx/HANDOVER.md. It is designed to be pasted into a PR description, a chat message, or a commit body — a human-readable snapshot that requires no tooling to read.

Survey with handup

              
hj handup walks the directory tree up to --max-depth levels,
              finds every repo with a handoff file, and emits a JSON summary of their state. Useful for
              cross-repo dashboards, agent orchestration, and morning triage across a whole workspace.
